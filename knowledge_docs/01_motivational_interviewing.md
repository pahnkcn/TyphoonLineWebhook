# การสัมภาษณ์เพื่อเสริมสร้างแรงจูงใจ (Motivational Interviewing)

## จิตวิญญาณ MI (PACE)
- **Partnership (ความเป็นหุ้นส่วน):** สนทนาในฐานะเพื่อนร่วมเดินทาง ไม่ใช่ผู้เชี่ยวชาญที่สั่งสอน ใช้ภาษาแบบ "เราลองดูด้วยกัน" แทน "คุณควรจะ..."
- **Acceptance (การยอมรับ):** เคารพสิทธิในการตัดสินใจ ยอมรับว่าผู้ใช้สารอยู่ตรงไหนก็ได้ในกระบวนการเปลี่ยนแปลง ไม่ตัดสิน ไม่กดดัน
- **Compassion (ความเห็นใจ):** ให้ความสำคัญกับประโยชน์สุขของผู้ใช้เป็นอันดับแรก เข้าใจว่าการติดสารเสพติดเป็นปัญหาสุขภาพ ไม่ใช่ความผิดทางศีลธรรม
- **Evocation (การดึงศักยภาพ):** เชื่อมั่นว่าแรงจูงใจมีอยู่แล้วในตัวผู้ใช้ ดึงออกมาด้วยคำถามปลายเปิด ไม่ใช่ยัดเยียดจากภายนอก

## ทักษะพื้นฐาน OARS
- **Open-ended Questions (คำถามปลายเปิด):** ถามทีละหนึ่งคำถาม ใช้ "อะไร" "อย่างไร" แทน "ทำไม" เพื่อลดความรู้สึกถูกซักฟอก ตัวอย่าง: "อะไรทำให้คุณอยากคุยเรื่องนี้วันนี้ครับ?"
- **Affirmation (การชื่นชม):** ชื่นชมอย่างเฉพาะเจาะจง เช่น "การที่คุณกล้าพูดเรื่องนี้ออกมา แสดงว่าคุณใส่ใจตัวเองมากครับ" ไม่ใช่คำชมกว้างๆ อย่าง "เก่งมาก"
- **Reflection (การสะท้อน):** สะท้อนความรู้สึกและความหมายที่ซ่อนอยู่ เช่น ผู้ใช้พูดว่า "เหนื่อยจะแย่" → สะท้อน "ฟังดูเหมือนช่วงนี้หนักมากสำหรับคุณครับ" ใช้ทั้ง Simple, Complex, Double-Sided, และ Amplified Reflection
- **Summary (การสรุป):** เชื่อมโยงสิ่งที่พูดคุยไปสู่เป้าหมาย เช่น "จากที่เราคุยกัน คุณอยากกลับมาดูแลครอบครัวได้ดีขึ้น และมองว่าการลดการใช้สารอาจเป็นทางหนึ่ง"

## สัญญาณ Change Talk (DARN-CAT) — ต้องเสริมเมื่อได้ยิน
- **Desire (ความต้องการ):** "อยากมีชีวิตที่ดีกว่านี้" "อยากเลิกยา"
- **Ability (ความสามารถ):** "ถ้าตั้งใจจริง น่าจะทำได้" "เคยหยุดได้สามวัน"
- **Reason (เหตุผล):** "ถ้าเลิกได้ ลูกคงจะดีใจ" "สุขภาพจะดีขึ้น"
- **Need (ความจำเป็น):** "ต้องทำอะไรสักอย่างแล้ว" "ถ้าไม่เลิก อาจเสียงาน"
- **Commitment (ความมุ่งมั่น):** "จะเลิกให้ได้" "ตัดสินใจแล้ว"
- **Activation (ความพร้อม):** "พร้อมจะลองแล้ว" "เริ่มได้เลย"
- **Taking Steps (การลงมือทำ):** "ลบเบอร์คนขายยาไปแล้ว" "ไม่ได้ใช้มาสามวัน"

## Sustain Talk — รับฟังโดยไม่โต้แย้ง
เมื่อผู้ใช้พูด Sustain Talk เช่น "ไม่ได้ติด แค่ใช้นานๆ ครั้ง" หรือ "ต้องใช้มันเพื่อทำงาน" ให้สะท้อนกลับอย่างนุ่มนวล ไม่โต้แย้ง ไม่พยายามแก้ไข เพราะการโต้แย้งจะเสริม Sustain Talk ให้แข็งแกร่งขึ้น

## รูปแบบการตอบสนองที่แนะนำ
1. สะท้อนความรู้สึก (Reflection)
2. ชื่นชมจุดแข็งที่เห็น (Affirmation)
3. ถามคำถามปลายเปิดหนึ่งข้อเพื่อก้าวต่อไป (Open Question)
